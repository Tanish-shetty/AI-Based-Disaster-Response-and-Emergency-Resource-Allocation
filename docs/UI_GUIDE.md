# Interactive dashboard guide

The updated dashboard keeps the academic accountability workflow and adds interactive exploration across all ten workspaces.

- **Overview:** select a fictional city marker to inspect its score, flood depth, confidence, rank and recommended teams. Action buttons open the ranking, simulator or review page.
- **Disaster Scenario:** filter area categories and select an area from the schematic or inspector. Download its observed records and explore relationships between flood depth and vulnerability.
- **AI Priority Analysis:** search by area, filter priority bands and show mandatory-review cases. Select a table row for its details. Switch to resource distribution and choose the resource to compare. Export filtered recommendations.
- **Explainable AI:** choose an area, control the number and direction of SHAP contributions, inspect class probabilities and view missing or observed inputs. Download actual computed contributions.
- **Ethical Risk Simulator:** change the shared sidebar scenario, then switch between before/after scores, score changes and rank movement. Inspect resource transfers separately and download the complete comparison.
- **Human Review:** edit the resource table or use Quick resource transfer. The displayed totals update before authorization. Restore AI proposal discards your draft edits. Add a reason for changes, select synthetic roles and confirm review to authorize. Transfers are drafts until the complete plan is authorized; the original AI proposal remains in the journal.
- **Accountability Audit:** search IDs, reviewers and reasons; filter Pending, Accept and Override decisions; explore the decision timeline, recommendations, input snapshots and full records. Export the filtered evidence.
- **Stakeholder Accountability:** filter responsibilities by stakeholder and inspect the ethical-principle mapping.
- **Results & Findings:** choose the model-comparison metric and examine class recall, confusion counts and accountability-readiness dimensions.
- **Recommendations:** explore safeguards by data/model, human-decision or audit/governance stage.

The city layout is illustrative, contains no real geographic positions and contributes no features to the ML model. Map marker size reflects priority and marker color reflects the score band. Class probabilities remain uncalibrated, and all displayed allocations remain academic simulations.

Sidebar scenario, confidence threshold and resource budgets are shared across pages. Review drafts are isolated by portfolio, so changing that context creates a separate pending decision set. Filtering a chart or table changes the view, not the recommendation or resource totals.
